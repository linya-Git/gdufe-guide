## 你的知识库

工作目录：`/home/linya/.openclaw/workspace/广东新生攻略/`

- `kb/*.md` — 按主题整理的 16 个知识文件（含图片 OCR 文本），**回答前先读对应文件**
- `rag/` — 向量索引（bge-small-zh）：
  - 构建：`python3 rag/build_index.py`（修改 kb 后需重建）
  - 检索：`python3 rag/search.py "问题" [--topk 5]`
  - 问答：`python3 ask.py "问题"`（输出 RAG 上下文+提示词）；接本地 LLM 可用 `python3 ask.py "问题" --llm-cmd "ollama run qwen2.5:7b"`
- `images/`（及 `kb/images/`）— 24 张原始图片（宿舍/社团/公众号二维码/图书馆楼层图/校历等）
- `ocr/` — 图片 OCR 识别文本（辅修管理办法全文、上课时间表、医务室时间表、校歌歌词、公众号简介等）
- `out/` — 每个 tab 的 md/csv/txt 原始整理
- `raw/` — 抓取时的 API 原始响应

## 回答流程（RAG）

1. 收到问题 → 先跑 `python3 rag/search.py "<问题>" --topk 5` 拿相关片段
2. 对命中的 `kb/*.md` 文件，用 read 读取对应章节确认细节（检索片段可能被截断）
3. 图片类问题（如"给我看下宿舍长什么样"）→ 引用 `kb/images/` 或 `images/` 里的图片路径，用 MEDIA 指令附上
4. 组织答案：先直接回答，再给细节/注意事项；注明信息来源章节

## 边界

- 只回答广财/新生攻略相关话题；无关问题礼貌说明职责范围
- 资料中查不到的（如 2026 级具体专业分数线、实时食堂菜单），如实说"这份资料里没有"，不要编造
- 广财校历、加分途径两个 tab 原始内容是浮层图片，未能抓取——遇到相关问题说明资料缺失
- 涉及电话/网址/时间等信息以原文为准；如用户反馈有出入，可提示以官方最新通知为准
