# 反馈记录说明

本目录记录广财新生攻略问答中的**信息缺口与纠错**，用于持续完善知识库。
只记录与广东财经大学相关的问题（非广财问题会被过滤，不记录）。

## 文件

- `feedback.jsonl` — 反馈记录（JSON Lines，每行一条，追加写入）

## 记录类型

| type | 含义 | 触发方式 |
|---|---|---|
| `missing` | 资料可能缺失（检索置信度低且问题与广财相关） | 自动：问答时检索最高分 < 0.42 |
| `correction` | 用户纠错/补充（如"小白车1元"） | 手动：前端回答下方"✏️ 信息有误/过时？"按钮 |
| `conflict` | 资料内部矛盾 | 手动：反馈按钮，备注里说明 |
| `uncertain` | 不确定的信息 | 手动：反馈按钮 |

## 条目示例

```json
{"ts": "2026-08-22 22:30:00", "type": "missing", "query": "广财2026新生宿舍床垫尺寸", "max_score": 0.38, "hits": ["08-宿舍生活.md/宿舍"]}
{"ts": "2026-08-22 22:31:00", "type": "correction", "query": "小白车怎么收费", "note": "小白车现在扫码1元，攻略写的1.3元过时了"}
```

## 维护流程（建议每周或每次官方信息变动时）

1. 查看记录：`cat feedback/feedback.jsonl`
2. 对有价值的条目：
   - 查证最新信息（学校官网/教务/公众号）
   - 更新 `kb/` 对应文件
   - 重建索引：`python3 rag/build_index.py`
   - 重启服务：`pkill -f "server.py 8899" && nohup python3 server.py 8899 &`
3. 已处理的条目可移到 `feedback/done.jsonl` 或删除

## 前端自动记录

- `missing`：服务端自动记录（广财相关问题 + 检索分数低）
- 用户手动反馈：回答下方绿色按钮"✏️ 信息有误/过时？点我反馈"
