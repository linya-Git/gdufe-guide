# 广东财经大学大数据与人工智能学院 - 党务服务中心招新指南

## 学院简介

大数据与人工智能学院（简称"大艺院"）是学校重点建设的工科学院，融合大数据、人工智能、计算机科学等前沿领域，培养具有数据思维和智能技术能力的高素质应用型人才。

### 学科特色
- 数据科学、人工智能、计算机科学与技术
- 产教融合、项目驱动的教学模式
- 与行业龙头企业共建实验室和实习基地

## 党务服务中心介绍

### 组织定位
党务服务中心是大艺院党委领导下的学生服务平台，承担学院党建宣传、学生事务服务、新媒体运营等工作。

### 主要职能
1. **党建宣传**：学院党组织活动宣传、理论学习材料整理
2. **学生服务**：通知发布、活动组织、信息收集
3. **新媒体运营**：微信公众号内容策划与编辑
4. **行政辅助**：会议记录、文档整理、活动筹备

- 活动部（活动策划执行）

## 招新信息

### 招新时间
每学年秋季学期初（9月），配合学校迎新工作同步进行。

### 招新对象
大艺院全体大一、大二学生，不限专业。

### 报名方式
- 现场报名：迎新期间设咨询点
- 线上报名：关注学院公众号获取报名表
- 推荐报名：辅导员/班主任推荐

### 面试流程
1. **报名审核**：提交报名表，筛选基本条件
2. **初试**：自我介绍 + 简单问答（考察表达能力、服务意识）
3. **复试**：情景模拟/小组讨论（考察团队协作、问题解决能力）
4. **录用**：发放录用通知，进入试用期

## 常见面试问题

### 个人类
1. 请做一下自我介绍
2. 你为什么选择加入党务服务中心？
3. 你有什么特长或兴趣？
4. 你如何看待时间管理？

### 情境类
1. 如果活动当天突发状况，你会怎么处理？
2. 如果同事之间意见不合，你怎么协调？
3. 如果任务量大且时间紧，你怎么安排？
4. 如果你对上级安排有异议，你会怎么做？

### 专业类（技术岗）
1. 你会使用哪些办公软件？
2. 有没有新媒体运营经验？
3. 懂设计/剪辑吗？用什么工具？
4. 对Python/数据分析了解多少？
